# Proyecto Monodon

Micrositio del proyecto “Distribución y potencial reproductivo de *Penaeus monodon* en Samaná: Hacia una pesquería de control de esta especie invasora”.

## Desarrollo

```bash
npm install
npm run dev
```

Los cambios enviados a la rama `main` se publican automáticamente mediante GitHub Pages.

## Contenido editable

- Textos y datos repetidos: `src/site.ts`
- Estructura: `src/App.tsx`
- Diseño: `src/styles.css`
- Fotografías: `public/assets/`
